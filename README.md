# muqitv 电视壳 APK

这是一个 Android TV 的「壳」应用：打开就是全屏的 muqitv 网站（WebView 包装），
首次启动需要输入一次激活码，激活后即使拔掉安装用的 U 盘、清理缓存，也不会再弹出。

## 配置（如果以后要改）

打开 `app/src/main/java/com/muqitv/tvapp/Constants.kt`：

- `SERVER_URL`：网站地址，默认 `https://muqitv.com`
- `SITE_PASSWORD`：网站访问密码（服务器 `docker run -e PASSWORD=` 设置的那个值）
- `ACTIVATION_CODE`：App 自己的激活码，默认 `MUQI20250415`，可以改成任意字符串

改完后重新走一遍下面的编译流程即可。

## 怎么编译出 APK（GitHub Actions，免装软件）

1. 去 GitHub 新建一个仓库（Public/Private 都行），比如叫 `muqitv-tv-app`。
2. 把这个文件夹里的所有文件和文件夹（包括隐藏的 `.github` 文件夹）整个拖拽上传到仓库里
   （GitHub 网页的 "Add file" → "Upload files" 页面支持直接拖拽整个文件夹进去）。
3. 提交（Commit）之后，去仓库顶部的 **Actions** 标签页，会看到一个正在跑的工作流
   （"Build muqitv TV APK"），等它跑完变绿色勾。
4. 点进去这次运行记录，页面最下面 **Artifacts** 里有一个 `muqitv-tv-app-debug`，
   点击下载，解压后就是 `app-debug.apk`，这就是最终的安装包。

## 怎么装到电视上

1. 把 `app-debug.apk` 复制到一个 U 盘里。
2. 电视上插入 U 盘，用电视自带的「文件管理器」app（大部分安卓电视都有，没有的话可以先装一个
   免费的文件管理器 App，比如应用商店搜"文件管理"）找到 U 盘里的这个 apk 文件，点击安装。
   安装时如果提示"不允许安装未知来源应用"，去设置里允许一次即可。
3. 装好后在电视桌面找到 **muqitv** 图标打开。
4. 第一次打开会要求输入激活码：`MUQI20250415`（即 Constants.kt 里设置的那个值），
   输入正确后以后每次打开都会直接进入网站首页，不会再问。
5. 这时候就可以把 U 盘拔掉了，App 已经装在电视本地存储上，和 U 盘没有关系。

## 已知的限制

- 这个 App 本质是把网站包了一层壳，网站本身是给鼠标/触屏设计的，电视遥控器的方向键在
  浏览首页卡片时支持有限（返回键、播放器内的播放/暂停等按键没问题）。如果电视遥控器支持
  "空中鼠标"/触控板模式（大多数安卓电视遥控器长按"确定"或有专门按键可切换），
  用这个模式操作会顺畅很多。
- 退出应用：遥控器的返回键会先让网页自己后退（比如从播放页返回首页），
  已经在首页时再按返回键会退出 App。
